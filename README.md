# Satya AI Portfolio, Style 2

This version uses five separate pages:

1. Home
2. Experience
3. Skills and Education
4. Projects
5. Contact

## Home video behavior

The video starts automatically without sound, which browsers allow. The center icon is the only video control.

- Click the pause icon to pause.
- Click the resume icon to continue.
- When resumed by the visitor, the video plays with sound.
- There is no separate sound on or sound off button.

## AI assistant

The AI assistant appears on every page. Its default buttons are Projects, Contact, Experience, and About.

## Run locally

Open `index.html` in a browser. For the best result, use a local server such as VS Code Live Server.
